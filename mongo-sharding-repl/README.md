## Задание 4. Кеширование

### 1. Запустить все сервисы
```powershell
docker compose up -d
```

### 2. Запустите скрипт инициализации
###### Скрипт  инициализирует все необходимые настройки, а также выведет информацию о количестве записей.
```powershell
.\init-replication.ps1
```

```bash
.\init-replication.sh
```

### 3. Проверить приложение
#### Открыть в браузере по ссылке ниже (порт 8089 переопределен т.к. часто 8080 занят в самой ОС другими прогами)
```
http://localhost:8089/
``` 

### 4. Подготовка к следующему заданию
##### Удаление всех созданных томов
```powershell
docker compose down -v
```
